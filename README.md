# University Project 1 Web Application - Tickify

Tickify is an online ticketing system developed as a **group project at Fontys University of Applied Sciences**. The system allows users to browse events, register an account, and purchase tickets. Event organizers can create events and define ticket categories with their own prices and availability. Users can order up to **10 tickets per event**. Payments must be completed within **10 days**, otherwise the booking is cancelled. Tickify keeps **10% of each successful transaction** as revenue, while 90% is paid to the event organizer.

## Technologies Used

- HTML
- CSS
- PHP
